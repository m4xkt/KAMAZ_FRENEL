# Kamaz_frenel_mipt_project
## Описание проекта

Представленная программа численными методами считает интеграл Френеля.\\
С помощью данных рассчётов моделируется дифракционная картина за отверстиями разных форм.\\
За основу была взята лабораторная работа по общей физике №4.3.1 "Дифракция света" из учебной программы МФТИ.


## Сборка и запуск

Для успешной сборки и запуска проекта вам потребуется установить cmake (если вы не проходили двухсеместровый курс молодого программиста в МФТИ), а также библиотеку OpenCV. Описывать установку не буду - гугл пока у нас не забанен.

Итак, вы всё установили, теперь необходимо открыть терминал и с помощью команды `cd` перейти в папку с проектом.

Далее вам осталось всего-навсего скопировать пару строк, представленных ниже и вставить их себе в ... терминал...

**Linux**  
```bash
mkdir build && cd build
cmake ..
make
```

После успешной сборки исполняемый файл `fresnel_sim` появится в папке `build/`.

```bash
./fresnel_sim
```

Для MinGW64
cd Директория проекта
mkdir build
cd build
cmake -G "MinGW Makefiles" -DOpenCV_DIR="C:/msys64/ucrt64/lib/cmake/opencv4" ..
cmake --build .

> Если OpenCV не находится автоматически, при вызове `cmake` укажите каталог с `OpenCVConfig.cmake`:  
> `cmake .. -DOpenCV_DIR=C:/opencv/build`

Через CMD
cd Директория проекта
mkdir build
cd build
cmake --build build --config Release -- -j %NUMBER_OF_PROCESSORS%
